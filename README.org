* About the pipeline

The pipeline is currently comprised of 4 modules that are required for the complete LCS analysis plus the 5 module that is analysis itself. It is based on LCS pipeline used in the original [[https://github.com/CSOgroup/WGD][WGD paper.]]  See below for details. 

This pipeline is an extension of hic_pipeline, therefore it follows an input directory structure of the hic_pipeline. For more details please refer
to the CSO [[https://github.com/CSOgroup/hic_pipeline][hic_pipeline here]].

* Installation instructions

Clone repository and install dependencies.

#+begin_src
  git clone https://github.com/zenteka/LCS_analysis_pipeline.git
  ./install_lcs_pipeline.sh
#+end_src

* Input

For the analysis to run, the user needs to provide the following input:
- output directory of hic_pipeline, provided to the script as -i flag. See: data input.
- tsv table with desired comparisons. See: Sample comparisons input.

** Data input

Input directory structure must contain all samples with "aligned" with the thresholded contact maps in .hic and .mcool format.

#+begin_src bash
  ./{hic_sample}/aligned/inter_30.mcool
                        /inter_30.hic
#+end_src

** Sample input

Table in tsv format with desired comparisons. Please MAKE SURE that selected comparison correspond to directory/folder names in the hic_pipeline output. It is CRUCIAL for the pipline to work correctly. SAMPLE_1 is always a control sample.

| SAMPLE_1 (control)  | SAMPLE 2               |
| e.g. CPA_RB_AB_mega | e.g.CPA_RB_WGD_AB_mega |
 
* Output

** Data

Below is the output of the pipeline for one sample after running it with the following flags:

Directory 1_CalderOutput contains calder output at a user specified resolution.
Directory 2_Dumps contains Hi-C interactions. Each tsv file stores Raw counts, balanced counts and rescaled balanced counts at resolution provided -D and -d flags.
Directory 3_CalderSaddleOutput stores the output CalderSaddle script computed at a given hic resolution (-r flag). Calder saddle script takes as input compartment file from 1_CalderOutput at a given resolution (-b flag).

Directory 4_InsulationOutput stores the output of insulaion analysis with Fanc.

                4_InsulationOutput
