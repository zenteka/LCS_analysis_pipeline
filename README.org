  pip install -r pip.requiremnts.txt

* About the pipeline

The pipeline is currently comprised of 4 modules that are required for the complete LCS analysis which itself is the 5 module. It is based on LCS pipeline used in the original [[https://github.com/CSOgroup/WGD][WGD paper.]]  See below for details. 

This pipeline is an extension of hic_pipeline, therefore it follows an input directory structure of the hic_pipeline. For more details please refer to the CSO [[https://github.com/CSOgroup/hic_pipeline][hic_pipeline here]].


* Input

For the analysis to run, the user needs to provide the following input:
- output directory of hic_pipeline, provided to the script as -i flag. See: data input.
- script expects hic and mcool files. Different file formats are used by different analysis scripts.  
- tsv table with desired comparisons. See: Sample comparisons input.
  
** input (for every sample)
#+begin_src bash
  <input_path>/{hic_sample}/aligned/inter_30.hic
                                    inter_30.mcool
#+end_src

The .mcool file should include the resolutions that are necessary for the analysis:
- 10.000.000
- 1.000.000
- 50.000

In addition, KR normalization in the .hic file is required. If the normalization is not there (for example, you are starting from cool files) you can use `hictk` to add it (`ice`), using the `--name KR` parameter.

** Sample run  
#+begin_src bash
  ./Run_LCS_pipeline.sh -i <input_path> \  # hic_pipeline output; 1-4 moduels results will be saved in sample folders
		      -o <output_path> \        # where plots will be saved
		      -c <tsv file> \           # Comaprison tables
		      -p 40 \                   # Cores 
		      -g hg19                   # Genome: hg19 and hg38 supported currently
#+end_src

** Comparison table -c [comparison table flag]

Table with desired comparisons. Please MAKE SURE that selected comparison correspond to directory/folder names in the hic_pipeline output. It is CRUCIAL for the pipline to work correctly.
Simply, just open any table editor and make 2-column table like this, using folder names from hic_output.


| SAMPLE_1 (control)  | SAMPLE 2               |
| e.g. CPA_RB_AB_mega | e.g.CPA_RB_WGD_AB_mega |
 

* Output structure

** Output

Modules 1-4 generate output for each sample and place it in the sample directory.
This is where the LCS_main looks for the necessary file to run the analysis.

After completion of modules 1-4, each sample's directory should contain:

#+begin_src bash
   <input_path>/{hic_sample}/1_subcomp_50000                        
		  2_trans                                     
		  3_saddle
		  4_insulation
		  aligned                                                                                                  
#+end_src

**** Directory 1_subcomp_{bin_size}
Contains calder calls output at a given resolution. Resolution is currently hardcoded at 50 kbp.
*IMPORTANT:* Calder output column "start" has malformed index (it is 1-indexed). For the pipeline to run correctly,
the output is corrected to be 0-indexed.

**** Directory 2_trans
Inter-chromosmal contacts (DUMP_COOL output) at 1Gbp (Whole chromosome).
**** Directory 3_saddle
Stores the output calder saddle script computed at a given hic resolution. Calder saddle script takes as an input calder subcompartment bed file. 

**** Directory 4_insulation
Stores the output of insulation analysis with fanc. Boundaries and scores.

** Plots 

All the plots will be saved to the directory provided by the user in -o flag. Number of directories will correspond to the number of comparisons specified in the tsv file,


* LCS_main

** Main

LCS_main requires all the above input to run correctly. The script conducts full loss of chromatin segregation analysis. 

- Inter-chromomsomal LCS 
- Compartment LCS
- Boundary LCS
- Intra-chromosomal LCS
