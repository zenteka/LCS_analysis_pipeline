Clone repository:

  git clone https://github.com/zenteka/LCS_analysis_pipeline.git
  cd LCS_analysis_pipeline

Setup the environemnt:

#+begin_src bash
  conda/mamba/micromaba create -f environemnt.yml -n lcs_pipeline
  # It can happen some pip dep. are not resolved. In this case run:
  pip install -r pip.requiremnts.txt
#+end_src


* About the pipeline

The pipeline is currently comprised of 4 modules that are required for the complete LCS analysis which is the 5 module. IT is based on LCS pipeline used in the original [[https://github.com/CSOgroup/WGD][WGD paper.]]  See below for details. 

This pipeline is an extension of hic_pipeline, therefore it follows an input directory structure of the hic_pipeline. For more details please refer
to the CSO [[https://github.com/CSOgroup/hic_pipeline][hic_pipeline here]].

* Input

For the analysis to run, the user needs to provide the following input:
- output directory of hic_pipeline, provided to the script as -i flag. See: data input.
- tsv table with desired comparisons. See: Sample comparisons input.

** Data input [-i flag]

Input directory structure must contain all samples with "aligned" with the thresholded contact maps in .hic and .mcool format.

#+begin_src bash
  ./{hic_sample}/aligned/inter_30.mcool
                        /inter_30.hic
#+end_src


** Comparison table -c [comparison table flag]

Table with desired comparisons. Please MAKE SURE that selected comparison correspond to directory/folder names in the hic_pipeline output. It is CRUCIAL for the pipline to work correctly.
Simply, just open any table editor and make 2-column table like this, using folder names from hic_output.


| SAMPLE_1 (control)  | SAMPLE 2               |
| e.g. CPA_RB_AB_mega | e.g.CPA_RB_WGD_AB_mega |
 

* Output structure

** Data

Modules 1-4 generate output for each sample and place in the sample directory.
This is where the LCS_main looks for the necessary file to run the analysis.

After running the lcs pipeline wtih -b 50000 and -r 1000000 flags, directory structure should look like this:

#+begin_src bash
   ./{hic_sample}/1_CalderOutput_50000                        
		  2_Dumps                                     
		  3_CalderSaddleOutput_r10000000              
		  4_InsulationOutput                          
		  aligned                                                                                                  
#+end_src

**** Directory 1_CalderOutput_{bin_size}
Contains calder output at a user specified resolution. Resolution controlled by -b flag.

**** Directory 2_Dumps
Dump output (intrachromosomal cotnacts).

**** Directory 3_CalderSaddleOutput_r{resolution}
Stores the output CalderSaddle script computed at a given hic resolution (-r flag). Calder saddle script takes as an input compartment file from 1_CalderOutput computed at a given bin_size (-b flag).

**** Directory 4_InsulationOutput
Stores the output of insulation analysis with fanc.



** Plots 

All the plots will be saved to the directory provided by the user in -o flag. Number of directories will correspond to the number of comparisons specified in the tsv file,
plus one directory for Interchromosomal LCS analysis heatmap output for each sample.


* LCS_main

** Main

LCS_main requires all the above input to run correctly. The script conducts full loss of chromatin segregation analysis. 

- Inter-chromosomal Inter-chromomsomal LCS
- Compartment LCS
- Boundary LCS
- Intra-chromosomal LCS
